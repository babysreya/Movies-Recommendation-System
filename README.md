# 🎬 Movie Recommendation System

A Content-Based Movie Recommendation System built using Machine Learning, NLP and Streamlit. The application recommends movies similar to a selected movie by analyzing genres, keywords, cast, crew, and overview information.

## 🚀 Live Demo

https://movies-recommendation-system-fh6w.onrender.com/

## 📌 Features

* Content-Based Recommendation Engine
* Interactive Streamlit User Interface
* Movie similarity using Cosine Similarity
* Fast recommendations with vectorized movie metadata
* Lightweight deployment optimized for cloud platforms
* Responsive and easy-to-use interface

## 🛠️ Tech Stack

### Frontend

* Streamlit

### Backend

* Python

### Machine Learning

* Scikit-Learn
* CountVectorizer
* Cosine Similarity

### Data Processing

* Pandas
* NumPy

## 📂 Dataset

Dataset used:

TMDB 5000 Movies Dataset

Files:

* tmdb_5000_movies.csv
* tmdb_5000_credits.csv
